Comment intégrer Kael

Suivez ces étapes simples pour connecter Kael à vos outils :

  1. Accédez à la section Intégrations dans votre compte Kael
  2. Sélectionnez l'outil que vous souhaitez connecter
  3. Connectez-vous à votre compte sur l'outil
  4. Configurez les permissions nécessaires
  5. Commencez à utiliser Kael avec vos outils préférés

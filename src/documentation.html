Premiers pas

Bienvenue dans la documentation de Kael System ! Cette section vous guide à travers les bases de l'utilisation de notre plateforme.

Prérequis

  • Un navigateur web moderne
  • Un compte Kael System (gratuit)
  • Accès à Internet

Création d'un compte

Pour commencer à utiliser Kael System :

  1. Accédez à notre page d'inscription
  2. Remplissez le formulaire avec vos informations
  3. Confirmez votre adresse email
  4. Connectez-vous à votre compte

Installation

Kael System peut être utilisé directement depuis votre navigateur sans installation nécessaire. Pour une utilisation avancée, vous pouvez également déployer une instance locale.

Version hébergée

La version hébergée est la plus simple à utiliser :

  • Accédez à notre site web
  • Connectez-vous avec vos identifiants
  • Commencez à utiliser les fonctionnalités

Installation locale

Pour une installation locale :

git clone https://github.com/votre-repo/kael-system.git
cd kael-system
pip install -r requirements.txt
python app.py

Configuration

Configurez votre environnement Kael System selon vos besoins spécifiques.

Paramètres généraux

Accédez à la section "Paramètres" dans votre interface pour :

  • Configurer les notifications
  • Personnaliser l'apparence
  • Gérer les utilisateurs
  • Configurer les alertes

Variables d'environnement

Certaines configurations peuvent être définies via des variables d'environnement :

  • PORT: Port d'écoute du serveur (par défaut: 8000)
  • DEBUG: Mode debug (true/false)
  • SECRET_KEY: Clé secrète pour les sessions

Référence API

Documentation complète des endpoints disponibles :

Endpoints principaux

Méthode Endpoint Description
GET /health Vérification de santé du service
GET /api/health Vérification de santé de l'API
GET /api/sites Liste des sites configurés

Dépannage

Solutions aux problèmes courants rencontrés avec Kael System.

Problèmes de connexion

  • Vérifiez votre connexion internet
  • Assurez-vous que le port requis n'est pas bloqué
  • Essayez de vider le cache de votre navigateur

Problèmes de performance

  • Redémarrez le service
  • Vérifiez l'utilisation des ressources système
  • Contactez notre support technique
